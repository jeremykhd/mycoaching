# Vue Component Conventions — MyCoaching

Guide for writing consistent Vue 3 components across the project.

## When to Apply

Reference these guidelines when:
- Creating a new component
- Using or extending UI primitives (`Ui*` components)
- Working with the app layout (sidebar, mobile menu)
- Styling with TailwindCSS
- Handling responsive behavior (mobile vs desktop)
